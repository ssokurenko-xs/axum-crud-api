# 🦀 Rust Axum CRUD API

A high-performance CRUD REST API built with **Rust**, **Axum**, **SQLx**, and **Postgres**, fully containerized with **Docker**.

## Architecture

The application consists of a Rust backend (Axum) communicating with a Postgres database, orchestrated via Docker Compose.

[![Backend Architecture](https://github.com/user-attachments/assets/cfaa9b5d-2b95-4103-b820-5e6fe1d340ce)](https://youtu.be/cJyl9e2oqHY)
*(Click the image to learn more in the video)*

## 🚀 Tech Stack

- **Language:** Rust 🦀
- **Framework:** [Axum](https://github.com/tokio-rs/axum) (0.8)
- **Database:** PostgreSQL
- **ORM/Querying:** SQLx
- **Containerization:** Docker & Docker Compose

## 🛠️ Prerequisites

Before starting, ensure you have the following installed:
- [Docker Desktop](https://www.docker.com/products/docker-desktop/)
- [Rust & Cargo](https://www.rust-lang.org/tools/install) (optional if running fully in Docker)
